## What is it?

The Stadium in Vice City has lights all over, yet none of them actually light up. This fixes that.

## Changelog

??? note "Click to view the full changelog"
    !!! info
        Exact files edited for each change will be in brackets () at the end of the change when possible.

    **v1.0.0** (09/08/2018)

    - Initial release.
    - Added coronas to the light models in and around the Hyman Memorial Stadium. (downtown.ide)
    - Removed the random red coronas from the roof of the Hyman Memorial Stadium and instead added blue coronas to the blue light models. (downtown.ide)

## Download and Installation

1. Download the latest version of the mod from your preferred source.

    - GTA VC: [GitHub](https://github.com/TJGM/VC.ImprovedHymanMemorialStadium2DFX/releases){target="_blank" rel="noopener"} or [Mega](https://mega.nz/folder/1zYhFRjZ#riUYBhzkjo6mJZ7rQR7RNw){target="_blank" rel="noopener"}.

2. Open the mod archive you downloaded and move the `Improved Hyman Memorial Stadium 2DFX vX.Y.Z` folder from the archive into your `modloader` folder.

3. If you're using Project 2DFX, replace `VCLodLights.dat` with the one included in the `Project 2DFX Support` folder. (optional)
