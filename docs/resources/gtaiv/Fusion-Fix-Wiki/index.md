## Introduction
Welcome to the unofficial **Fusion Fix Wiki** by TJGM! The goal of this wiki is to document, highlight and keep track of as much Fusion Fix information for Grand Theft Auto: IV as possible.

Fusion Fix fixes and improves so many things in GTA IV, that it can be hard to keep up with what exactly the mod does. I'll try my best to provide as much information about as many changes as I can via this page.

This Wiki is currently based on Fusion Fix v5.1.
